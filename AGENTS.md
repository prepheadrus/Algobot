# Algobot AI Agent Context

## Project Goal
This repository is the foundation for an algorithmic trading application named CryptoAutomat. The system automates cryptocurrency trading using predefined technical indicators and market analysis.

## Core Technologies
- Python 3.10+
- Pandas for data manipulation
- CCXT for cryptocurrency exchange integrations

## AI Agent Guidelines
- Write comprehensive unit tests for every new feature using `pytest`.
- Always handle API rate limits and network timeouts explicitly.
- Document all public functions and classes with docstrings.
- Ensure strict separation between the data fetching layer and the trading logic layer.
- Do not use external libraries without explicit permission in the prompt.
